1. GIT Lo usamos para guardar cambios y controlar versiones

2. ISSUE Lo creamos para apuntar tareas errores o mejoras

3. PUSH Lo usamos para subir nuestros cambios a GitHub

4. SPRINT Es un periodo corto para hacer unas tareas

5. FORK Es una copia de un repositorio en nuestra cuenta de GitHub

6. STATUS Nos indica cómo va una tarea

7. CLON Es una copia del repositorio en nuestro ordenador

8. KANBAN Lo usamos para organizar las tareas por columnas

9. COMMIT Lo hacemos para guardar los cambios realizados

10. ASSIGNEE Es la persona encargada de una tarea

11. GITHUB Lo usamos para subir proyectos y trabajar en equipo

12. BACKLOG Es la lista de tareas que nos quedan por hacer

13. PULL Lo usamos para actualizar nuestro repositorio con los últimos cambios

14. BOARD Es el tablero donde vemos las tareas pendientes y terminadas

15. UPSTREAM Es el repositorio original del que viene nuestra copia

16. SCRUM Es una forma de organizar el trabajo en equipo

17. VIEW Es una forma de ver y organizar las tareas

18. PULL REQUEST La hacemos para proponer cambios en un proyecto

19. ITERATION Es un periodo en el que organizamos el trabajo

20. SPRINT BACKLOG Es la lista de tareas que vamos a hacer durante un sprint
